# 稿件格式（deck.json）

一个 JSON 文件 = 一套 PPT。UTF-8 保存，图片路径相对这个 JSON 所在文件夹。

```json
{
  "title": "整套标题（演讲稿文件用）",
  "masthead": "页眉左上角的小字，比如 报告名 · 单位",
  "style": "consulting",
  "slides": [
    {"layout": "cover", "kicker": "ANNUAL REVIEW · 2026", "title": ["第一行", "第二行"], "subtitle": "一句话副标题",
     "meta": "汇报人 · 日期", "stats": [{"value": "12.5亿", "label": "营收"}], "notes": "这一页要说的话"}
  ]
}
```

## 每页都能写的字段
| 字段 | 说明 |
|---|---|
| layout | 版式名，见下表（必填） |
| kicker | 眉标，标题上方的小标签，2–6 个字或英文短语 |
| title | 结论式标题。太长要换行时写成列表 `["第一行", "第二行"]` |
| subtitle | 标题下一行灰色小字，补充口径或范围 |
| notes | **演讲稿**（必填）。口语化，这一页要讲的完整的话，60–150 字 |
| source | 数据来源，显示在页脚。有数字的页必填 |
| credit | 图片署名（用了网上图片时必填） |
| transition | 翻页效果：fade（默认）/ push / cube / flip / ripple / none |
| anim | 写 "none" 关掉这页的动画 |

文字里用 `**重点**` 标出强调词，会变成强调色加粗。**一页只标 1 处**。

## 版式（layout）
| layout | 要写的字段 | 什么时候用 |
|---|---|---|
| cover | title（列表两行）, subtitle, kicker, meta, stats（可选 3–4 个数字）, badge（封面大字，默认 AI，2–3 个字符）, badge_note | 封面 |
| agenda | items[{title, text, image?}] 3–5 个 | 目录 |
| section | no（"01"）, title, subtitle, image?, credit? | 章节过渡页 |
| kpi | items[{label, value, delta, trend: up/down, highlight, note}] 2–4 个；再加 split 或 summary | 一组关键数字 |
| stat | value, label, delta, text, gauge{value, text, label}? | 一个特别重要的数字 |
| chart | chart{…}, insights[2–3 条] 或 stats[{label, value, note}] | 一张图 + 右侧解读 |
| charts | panels[{title, note, chart, takeaway}] 两个 | 两张图对比 |
| table | columns[], rows[[]] ≤ 6 行, highlight_row, summary | 多项对比 |
| timeline | items[{time, title, text, highlight}] 4–6 个, chart{title, bars[], line[], line_name}? | 发展历程 |
| process | steps[{title, text, stage, highlight}] 3–5 个, summary | 步骤、打法、路线图 |
| points | items[{title, text}] 2–6 个 | 几个并列要点 |
| compare | left{tag, title, items[]}, right{…} | 过去 vs 现在、A vs B |
| arch | layers[{name, items[], highlight}]（从上到下） | 分层架构 |
| donut_story | segments[{name, value, label}], center["标签", "总数"], note, teaser | 结构变化（两页连用，见下） |
| hero | image, title, subtitle, stats, credit | 满版照片 + 大标题 |
| split | image, title, bullets[], stats, credit | 左文右图 |
| gallery | items[{image, tag, stat, stat_label, title, text}] 3 个 | 几个案例/场景 |
| quote | text（可写列表断行）, by, image? | 金句、结论 |
| end | title, subtitle, credits | 结尾 |

### 字段补充
- **kpi.split**：下方一根比例条。`{"title": "…构成", "note": "右侧小字", "parts": [{"name": "A", "value": 206.4, "label": "206.4 万"}, {"name": "B", "value": 277.4}]}`
- **kpi.items[].lower_is_better**: true 时下降显示成绿色。
- **timeline.chart**：时间线下方的「柱 + 折线」，bars 和 line 的个数必须等于 items 个数；line 是百分比（0–100）。
- **process.steps[].stage**：now / next / later，显示在台阶右上角。
- **table.bars**：给哪几列加数据条（列号从 0 开始）；不写时数字列自动加。
- **donut_story 两页连用**：第一页画现状并写 `teaser`（如「2026 年会怎么变？」）；第二页写 `"continue": true, "transition": "none"` 和 `annotations[{title, text, trend: up/down}]`，两页的 segments 名字和顺序要一样。

## 图表（chart）
```json
{"type": "auto", "categories": ["2021", "2022", "2023"], "series": [{"name": "营收", "values": [10, 12, 15]}],
 "unit": "亿元", "highlight": 2}
```
- type：auto（推荐，自动选）/ column 柱 / bar 横条 / line 折线 / doughnut 环形
- 多个系列：series 里写多个 `{"name", "values"}`，最多 3 个
- 环形图可写 `"center": "合计\n18.3 亿"`
- `highlight`：要高亮的那个类别的序号（从 0 开始），其他自动变灰
- `y_min`：折线图纵轴起点；`format`: "0.0" 保留一位小数

## 排不满时（自查报「下半页空」）
| 版式 | 加什么 |
|---|---|
| kpi | `split` 构成条，或 `summary` 一句结论 |
| timeline | `chart` 组合图 |
| table | `summary`，或减少列让行高变大 |
| process | `summary` |
| points | 每项多写一句，或改用 process / chart |
| 其他 | 换成信息更多的版式：chart 加 insights，或改用 charts 两图对比 |

# 动效指南（从 html-ppt-skill 的 47 个动效学来，转成 PowerPoint 原生动画）

## 〇、节奏硬指标（用户反馈 2026-11-22）
- 整体比网页版快 1.3 倍（anim.SPEED = 1.3，生成时统一换算）。
- 翻到新页后第一个动画 ≤ 0.1 秒开始；页面切换默认 fast（0.5 秒）。
- **章节页不做慢推**：章节页通常 10 秒内翻走，长动画会让演讲者多点一下才能翻页。其他页 Ken Burns 默认关闭，需要时用 `"kenburns": 毫秒` 打开。
- 循环动效（波纹、卫星、闪烁）只做氛围，不影响翻页。

## 一、编排原则（最重要）
1. **一页一个主角动效**，其他元素用 fade-up / fade 做配角。主角放在这页最想让人记住的东西上（数字、图表、照片）。
2. **节奏 = 标题先到 → 主角 → 细节**。标题 rise（0.7 秒），间隔 80–150 毫秒出下一个；同类元素错开 40–120 毫秒（stagger）。
3. **方向有含义**：左栏 fade-left、右栏 fade-right；时间线从左往右；架构自下而上；对比页中间箭头最后画出来。
4. **循环动效只做氛围**：信号波纹、节点闪烁要慢（2–3 秒一圈）、要淡，不能抢文字。
5. **讲解型页面用点击**：要点卡片加 `"click": true`，讲一点出一点；数据页一般自动播放。
6. **页面切换**：同一章节内用 morph（平滑，背景光晕会缓慢漂移，有高级感）；进新章节用 cube；全屏大图用 flythrough；结尾用 vortex。整份 deck 不要超过 4 种切换。

## 二、47 个网页动效 → PowerPoint 实现对照
| html-ppt 动效 | 在 PPT 里怎么做 | 用在哪 |
|---|---|---|
| fade-up / fade-down / fade-left / fade-right | 淡入 + 位移（原生） | 正文、卡片、左右两栏 |
| rise-in | 淡入 + 上移 10% + 轻微缩放 | 每页标题、全屏大图标题 |
| drop-in | 淡入 + 下落 + 1.08→1 缩放 | 引号、横幅 |
| zoom-pop | 0.6→1.06→1 回弹 | 章节编号、徽章、关键节点 |
| blur-in | 淡入 + 1.08→1 缩放（PPT 无模糊，用缩放模拟） | 封面揭示 |
| glitch-in | 透明度跳变 + 左右抖动（关键帧） | 科技、安全、故障类 |
| typewriter / letter-explode / word-cascade | 逐字淡入（按字母迭代） | 封面标题、金句 |
| stagger-list | 每项错开 40–120 毫秒 | 列表、网格、表格行 |
| counter-up / counter-explosion | **数字滚动**：30 帧（约 40fps）、easeOutQuart，数字依次闪现，最后停在真实数值；中间帧平时放在页面外，不影响编辑 | KPI、巨型数字、大图上的数据 |
| path-draw | 擦除（从左往右） | 线条、箭头、时间轴、分隔线 |
| card-flip-3d | 宽度从 0 展开 | 图片墙、翻牌 |
| cube-rotate-3d | 页面切换：立方体 | 章节页 |
| page-turn-3d | 页面切换：翻页 | 故事型、杂志型 |
| perspective-zoom | 页面切换：飞越 | 进入全屏大图 |
| spotlight / ripple-reveal | 圆形展开 | 照片揭开 |
| kenburns | 强调：14–16 秒缓慢放大 1.06–1.10 | 所有出血大图 |
| shockwave | **信号波纹**：同心圆放大淡出，循环 | 5G/信号/影响力主题、重点节点 |
| constellation / knowledge-graph / neural-net | **网络连线**：线条依次出现，大节点循环闪烁 | 封面、章节页背景 |
| confetti-burst / confetti-cannon / firework | **彩纸爆发**：小色块从中心飞出、旋转、淡出 | 结尾、庆祝 |
| neon-glow | 透明度呼吸（循环） | 霓虹/终端主题的重点字 |
| pulse（自加） | 1→1.015 来回缩放 2 次 | 架构图的重点层 |
| 图表生长（chart.js 默认，第 29–31 号版式） | **用形状画图**：柱子顶部圆角、底边固定从 0 长到满高（easeOutQuart 约 1 秒，同时生长、轻微错开）；折线为平滑曲线 + 渐变面积，整条线、面积和数据点一起从 X 轴升起；环形各段同时用「轮子」扫出 = 顺时针生长 | 所有图表 |
| 表格逐行（网页没有） | 每行是一个组合，从左滑入 | 对比表 |
| marquee、gradient-flow、shimmer-sweep、parallax-tilt、morph-shape、starfield、matrix-rain、galaxy-swirl、particle-burst、magnetic-field、data-stream、gradient-blob、sparkle-trail、chain-react、orbit-ring、typewriter-multi | PPT 做不了实时粒子 / 鼠标交互，**降级**：粒子类→网络连线或彩纸；流动渐变→静态渐变；连锁脉冲→流程页的逐个弹出 + 箭头画出 | — |

## 二点五、讲故事的图表
数据变化要「演」出来，不要左右两栏摆数字。例：投资从通信网络搬到算力网络 → 两页 `donut_story`，第一页画 2025 年比例，第二页用平滑切换（morph）让同一个环形图转成 2026 年比例，再出原因卡片。
同理可用于：市场份额变化、成本结构变化、预算再分配。

## 三、版式 × 动效 默认搭配（生成器已内置）
| 版式 | 主角动效 | 配角 |
|---|---|---|
| cover 封面 | 标题逐字出现 + 中心信号波纹 + 网络连线 | 眉标淡入、渐变短线画出 |
| agenda 目录 | 各行左滑 + 分隔线画出 | 大标题 rise |
| section 章节 | 编号回弹 | 右侧照片圆形展开 + 慢推；无图时网络连线 |
| kpi 关键数字 | 数字滚动 | 卡片上浮、涨跌标签 |
| stat 巨型数字 | 大号数字滚动 | 右侧仪表盘：进度弧顺时针扫出 + 中心数字滚动 + 卫星绕轨道 + 外圈波纹（`gauge`） |
| chart / charts 图表 | 柱子逐根长出 / 折线画出 / 环形转圈 | 解读条从上往下擦出 |
| table 表格 | 逐行左滑 | 表头淡入 |
| timeline 时间线 | 按 html-ppt timeline.html 还原：每列（年份+圆点+标题+说明）整体 rise，错开 0.1 秒 | 细横线淡入 |
| process 流程 | 卡片依次弹出 + 箭头画出（连锁） | 编号缩放 |
| arch 分层架构 | 自下而上逐层擦出 | 标签弹出、重点层脉冲 |
| hero 全屏大图 | 照片慢推（Ken Burns） | 标题 rise、底部数字滚动 |
| split 图文 | 照片圆形展开 + 慢推 | 要点左滑、数字滚动 |
| gallery 图片墙 | 图片翻牌 | 说明上浮 |
| compare 对比 | 中间箭头画出 | 左右卡片从两侧进入 |
| donut_story 环形变形 | 两页连用，第二页 morph 补间比例 | 原因卡片 rise |
| quote 金句 | 逐字出现 | 引号下落 |
| end 结尾 | 彩纸爆发 + 标题回弹 | 渐变线画出 |

## 四、主题怎么选（36 套，来自 html-ppt）
- **行业汇报 / 政企**：corporate-clean、arctic-cool、minimal-white、swiss-grid
- **科技、通信、AI**：tokyo-night、aurora、nord、glassmorphism、catppuccin-mocha
- **路演 / 融资**：pitch-deck-vc、neo-brutalism、sharp-mono
- **品牌 / 杂志 / 长文**：editorial-serif、magazine-bold、japanese-minimal
- **消费 / 生活 / 小红书**：xiaohongshu-white、soft-pastel、sunset-warm
- **教学 / 工作坊**：solarized-light、academic-paper
深色主题配照片更出效果；浅色主题适合打印、投影仪较暗的会议室。

## 五、15 套完整 deck 学到的结构
- **汇报型（weekly-report、pitch-deck）**：封面 → 目录 → 关键数字 → 图表 ×2 → 表格 → 下一步 → 结尾。数字页紧跟封面，先给结论。
- **发布会型（product-launch）**：深色大图开场 → 浅色内容页，用照片和大数字制造节奏起伏。
- **分享型（tech-sharing、presenter-mode）**：每页都写逐字稿（我们写在备注里）。
- **讲故事型（xhs-*、dir-key-nav-minimal）**：一页一个观点，大字 + 大留白；章节页换图换色。
- 通用节奏：**每 3–4 页内容插一张章节页或全屏大图**，避免连续都是卡片。
